# سامانهٔ بهفراز — نسخهٔ آنلاین (GitHub Pages)

آدرس: https://hmnoise-creator.github.io/behfarazele/

- بدون صفحهٔ ورود و بدون سرور. پیش‌فاکتورها، کارتابل و یادداشت‌ها در حافظهٔ مرورگر **همان دستگاه** ذخیره می‌شوند.
- برای انتقال پیش‌فاکتورها بین دستگاه‌ها از «دانلود گزارش / آپلود گزارش (JSON)» داخل هر ابزار استفاده کنید.
- حضور و غیاب، فوروارد به همکار و بک‌آپ سرور فقط در سامانهٔ شبکهٔ دفتر کار می‌کنند.
- کد حالت آنلاین در بلوک `<script id="bfStaticMode">` بالای هر صفحه است. با پاک کردن آن، فایل دوباره نسخهٔ دفتر می‌شود.

# سرور (Node.js)

فایل‌های سرور هنوز داخل مخزن نیستند. `server.js` (و `package.json` اگر هست) را از کامپیوتر سرور شرکت در **ریشهٔ مخزن** بگذارید (کنار پوشهٔ `public`).

## ⚠️ قبل از اولین commit حتماً چک کنید

- **رمزها و نام‌های کاربری** نباید داخل `server.js` نوشته شده باشند. آن‌ها را به فایل `.env` (یا `users.json`) منتقل کنید. این فایل‌ها در `.gitignore` هستند و آپلود نمی‌شوند. نمونه: [`.env.example`](../.env.example)
- **دادهٔ واقعی** (سفارش‌ها، حضور و غیاب، پشتیبان‌ها، فایل‌های JSON دیتابیس) را داخل پوشهٔ `data/` نگه دارید. این پوشه هم آپلود نمی‌شود.

بعد از اضافه‌کردن، این پوشه (`server/`) را می‌توانید پاک کنید.

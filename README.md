# سامانهٔ بهفراز — نسخهٔ آنلاین (GitHub Pages)

آدرس: https://hmnoise-creator.github.io/behfarazele/

- بدون صفحهٔ ورود و بدون سرور. پیش‌فاکتورها، کارتابل و یادداشت‌ها در حافظهٔ مرورگر **همان دستگاه** ذخیره می‌شوند.
- برای انتقال پیش‌فاکتورها بین دستگاه‌ها از «دانلود گزارش / آپلود گزارش (JSON)» داخل هر ابزار استفاده کنید.
- حضور و غیاب، فوروارد به همکار و بک‌آپ سرور فقط در سامانهٔ شبکهٔ دفتر کار می‌کنند.
- کد حالت آنلاین در بلوک `<script id="bfStaticMode">` بالای هر صفحه است. با پاک کردن آن، فایل دوباره نسخهٔ دفتر می‌شود.
- **رمز ورود:** هر صفحه قبل از نمایش رمز می‌خواهد (بلوک `<script id="bfPassGate">` بالای هر صفحه). رمز فقط به‌صورت هش SHA-256 در کد است؛ برای عوض کردن رمز، مقدار `HASH` را در همهٔ صفحه‌ها عوض کنید. هر مرورگر بعد از یک بار ورود درست، رمز را به خاطر می‌سپارد.
- **انبارها (انبار مرکزی بسیج و سامانه انبار مجموعه):** در نسخهٔ آنلاین فقط برای مشاهده‌اند. داده از `data/wh.enc.json` و `data/whs.enc.json` خوانده می‌شود که با رمز ورود رمزگذاری شده‌اند (AES-256-GCM)، پس متن داده در GitHub خوانا نیست. برای به‌روز کردن داده: `node tools/anbar-online-export.js <مسیر behfaraz.db> data <رمز>` و بعد commit.
